## Lessons Volume I — Lessons 1–45 (`book1-for-CD.pdf`)

Cite as `[Lessons-I L<N>, p.<page>]`. 122 pages.

Pedagogical, example-driven. Each lesson has a "Topics Covered" header, numbered Key Points, and example charts. Best uses:

- Teaching-style explanations of fundamentals (chart basics, divisional charts, dasha systems)
- Example charts illustrating yogas and combinations
- Chara karaka usage (Lesson 16 around p.60 onward)
- Birth time rectification (Lesson 17)
- Children (D-7) and career (D-10) analysis (Lesson 18)

## Lessons Volume II — Lessons 46–77 (`book2-for-CD.pdf`)

Cite as `[Lessons-II L<N>, p.<page>]`. 149 pages.

Advanced continuation. Use for deeper-cut techniques when the Textbook's treatment is too terse. Confirm page by opening the file before citing — the student-compiled nature means formatting varies.
